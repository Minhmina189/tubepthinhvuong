Backup & Restore

Xuất dữ liệu ra file JSON để backup, hoặc nhập lại từ file backup. Tất cả ảnh và nội dung đã chỉnh sửa đều được lưu trong file này.

Vùng Nguy Hiểm

Xóa toàn bộ dữ liệu đã lưu và khôi phục về nội dung mặc định ban đầu.

Hướng dẫn sử dụng

  1. Chọn mục cần chỉnh sửa ở thanh bên trái
  2. Click vào ô ảnh để upload ảnh từ máy tính
  3. Chỉnh sửa tên, mô tả trong các ô văn bản
  4. Nhấn Lưu thay đổi (hoặc Ctrl+S) để lưu
  5. Nhấn Xem trang để kiểm tra kết quả

Ảnh được lưu trực tiếp trong trình duyệt. Dùng Xuất JSON để backup và chuyển sang máy khác.
